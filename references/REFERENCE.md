## 指标说明（用于 `--metrics`，术语+白话+示例三段式）

- **环比**（MoM）：以上月=100 为基准。白话：和上个月比。示例：环比 100.3 = 比上月上涨 0.3%；环比 99.7 = 比上月下跌 0.3%。
- **同比**（YoY）：以上年同月=100 为基准。白话：和去年同一个月比。示例：同比 96.7 = 比去年同月下跌 3.3%。
- **定基**（fixed-base）：以统计局当期表头定义的固定基期为准（2021 年起基期 2020=100）。白话：和某个固定起点比，看累计变化。
- **累计平均**：表头形如"1—6月平均"，以上年同期=100 为基准。白话：今年 1 月到本月为止的平均水平与去年同期相比。

更多白话释义与直觉化换算规则见 `GLOSSARY.md`。

常见别名：

- `环比`：`环比指数`、`月环比`、`mom`、`MoM`
- `同比`：`同比指数`、`年同比`、`yoy`、`YoY`
- `定基`：`定基指数`、`fixed-base`
- `累计平均`：`累计`、`平均`、`1-本年累计平均`

可组合传参，例如：

```bash
python3 scripts/fetch_data.py --city 武汉 --metrics 环比,同比 --latest
python3 scripts/fetch_data.py --city 上海市 --metrics yoy --limit 12
python3 scripts/fetch_data.py --city 北京 --metrics 环比,同比,累计平均 --chart --limit 24
```

## 面积段（表3/表4 分类指数）

每页公告含 4 张表：表1 新建总指数、表2 二手总指数、表3 新建分类指数、表4 二手分类指数（每页渲染两遍，脚本自动去重）。分类指数按面积段分三档：

- `90m2及以下`（刚需小户型）
- `90-144m2`（改善型）
- `144m2以上`（大户型）

分类记录的 `metrics` 键格式为 `{面积段}_{指标}`，如 `90m2及以下_环比`。

## 结果字段

脚本顶层输出重点字段：

- `city`：规范化后的城市名
- `requested_city`：用户原始输入
- `matched_city`：实际匹配到的城市名
- `latest_period`：结果中的最新期次
- `record_count`：记录数
- `records`：核心数据列表
- `failed_periods` / `warnings`：部分期次抓取失败时的明细（不再静默吞掉）

若失败，错误 JSON 会区分：

- 城市不在 70 城列表中
- 指标无可用数据
- RSS 获取失败
- 网络请求失败
